# Bing Wallpaper

一个基于 Vue 3 + Vite 的 Bing 每日壁纸浏览与搜索网站。

项目从 Bing 壁纸数据仓库加载每日壁纸数据，支持时间线浏览、历史搜索、颜色搜索、高清查看、颜色分析和原图下载。

## ✨ 功能

* 🖼️ Bing 每日壁纸浏览
* 📅 时间线快速浏览历史壁纸
* 🔎 关键词搜索
* 📆 按日期搜索
* 🌈 按颜色搜索
* 🎨 图片主色调分析
* 🧬 图片色彩指纹
* 📊 108 个 HSV 色彩区域分析
* 🗂️ 全历史数据索引搜索
* ⚡ 按月份懒加载历史数据
* 🖼️ 缩略图 → 高清图渐进式加载
* 🔍 高清图片查看器
* 🎨 主色调展示与颜色复制
* 📥 原图下载
* 📊 原图下载进度显示
* 📱 移动端适配
* ☁️ 支持 Cloudflare Pages / Vercel 等静态部署方式

## 🖥️ 页面功能

### 首页

首页以卡片形式展示 Bing 壁纸。

每张壁纸包含：

* 日期
* 标题
* 描述
* 色彩指纹
* 壁纸缩略图
* 高清查看入口

### 色彩指纹

每张壁纸都会生成一个简化的色彩指纹。

底层数据使用：

```text
Hue × Saturation × Value
12 × 3 × 3
= 108 个色彩区域
```

首页为了保持卡片简洁，将 3 个 Value 区域合并展示，因此最终显示为：

```text
12 × 3
= 36 个色彩区域
```

色彩指纹用于快速了解一张图片的整体颜色组成。

> 色彩指纹描述的是整张图片的颜色分布，并不表示图片中的空间位置。

鼠标悬停在色彩区域上，可以查看对应的色相、饱和度和颜色占比。

## 🔎 搜索

搜索支持两种数据范围。

### 已加载数据

只搜索当前已经加载到浏览器中的壁纸数据。

适合日常浏览和快速搜索。

### 全部历史

选择“全部历史”后：

1. 前端首先加载 `data/index.json`
2. 在历史索引中查找匹配的日期
3. 将匹配日期按月份分组
4. 只加载包含匹配结果的月份 JSON
5. 在完整月度数据中进行最终匹配

因此不需要一次性加载全部历史 JSON。

这种方式可以在保持静态部署架构的情况下，支持较大规模的历史数据搜索。

## 🌈 颜色搜索

颜色搜索不是简单地比较一个 RGB 数值。

项目使用两层颜色信息：

### 主色调

使用图片主色提取结果，用于：

* 页面视觉展示
* 主色调查看
* 颜色选择

### HSV 色彩直方图

图片生成数据时，会对图片进行 HSV 分桶：

```text
Hue        12 桶
Saturation 3 桶
Value      3 桶

12 × 3 × 3 = 108
```

最终得到 108 个色彩区域。

颜色搜索会根据这些区域计算颜色分布相似度，因此可以比单纯比较一个主色更加细致。

---

## 📊 颜色分布

在壁纸详情页中，会显示完整的 108 色彩区域。

展示形式为：

```text
12 个 Hue
×
3 个 Saturation
×
3 个 Value

= 108 个区域
```

这些区域表示：

> 整张图片中，各个 HSV 颜色区间包含的像素数量。

它不是图片的空间缩略图。

例如：

```text
┌──────────────┐
│ 原始图片      │
│              │
│ 蓝天          │
│ 绿色森林      │
│ 棕色山体      │
└──────────────┘

        ↓ 颜色统计

┌────────────────────┐
│ 蓝色区域占比较高    │
│ 绿色区域占比中等    │
│ 棕色区域占比较低    │
└────────────────────┘
```

鼠标悬停在某个区域，可以查看：

* Hue 色相范围
* Saturation 饱和度
* Value 明度
* 该区域像素占比

## 🔬 图片数据

前端从独立的数据仓库加载 JSON 数据。

默认数据地址：

```text
https://raw.githubusercontent.com/chendada00/bing-data/main
```

也可以通过环境变量修改：

```env
VITE_DATA_BASE_URL=https://your-data-domain.example
```

例如使用 Cloudflare Pages 部署数据仓库后，可以将数据地址指向自己的 CDN 域名。

---

## 📁 数据加载方式

历史数据按照月份组织：

```text
data/
├── 2026/
│   ├── 01.json
│   ├── 02.json
│   ├── 03.json
│   └── ...
├── 2025/
│   ├── 01.json
│   └── ...
└── index.json
```

前端不会一次性加载全部历史数据。

普通浏览模式下：

```text
当前月份
   ↓
上一个有数据的月份
   ↓
继续向前加载
```

历史搜索模式下：

```text
关键词
   ↓
index.json
   ↓
匹配日期
   ↓
按月份分组
   ↓
加载对应月份 JSON
   ↓
最终搜索
```

## 🚀 本地运行

安装依赖：

```bash
npm install
```

启动开发服务器：

```bash
npm run dev
```

构建：

```bash
npm run build
```

预览生产构建：

```bash
npm run preview
```

可以通过 `.env` 配置数据地址：

```env

```

不配置时使用默认 GitHub Raw 地址。

例如：

* Vercel
* Cloudflare Pages
* GitHub Pages
* Netlify

```env
VITE_DATA_BASE_URL=https://your-data-domain.example
```
